Privacy Policy

Last updated: August 2026

autoshorts is a personal, single-operator automation tool. This policy explains how it handles data accessed through the Google and TikTok APIs it connects to.

Who uses this application

autoshorts is used only by its developer, to manage videos on the developer's own YouTube channel and TikTok account. It is not distributed to, or used by, any other end users, and it does not collect, process, or store personal information belonging to anyone other than the developer.

What data it accesses

Through the YouTube Data API, autoshorts accesses and manages data belonging to the developer's own YouTube channel only:

  • Uploading video files to that channel.
  • Setting a video's title, description, tags, and thumbnail image.
  • Scheduling when an uploaded video becomes public.
  • Reading basic channel information, to confirm uploads go to the correct channel.

Through TikTok's Content Posting API, autoshorts accesses and manages data belonging to the developer's own TikTok account only:

  • Uploading video files and publishing them as posts on that account.
  • Setting a post's caption/title.
  • Reading basic profile and posting-limit information (via creator_info), to confirm uploads go to the correct account and respect its limits.

No data from any other Google account, YouTube channel, TikTok account, or third party is accessed, collected, or shared.

Data storage and retention

An OAuth access/refresh token is stored per platform so the application can act on the developer's own channel and account without repeated manual sign-in. Each token is stored privately (not committed to source control, not shared with any third party) and used solely to call that platform's API on the developer's behalf. No video content, metadata, or account data is sold, shared, or used for advertising.

Google API Services User Data Policy

autoshorts' use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

TikTok API data use

autoshorts' use of information received from TikTok's APIs adheres to TikTok's Developer Terms of Service. Content published to TikTok through this tool carries no autoshorts branding or watermark added by the API call itself, in line with TikTok's content-sharing guidelines.
